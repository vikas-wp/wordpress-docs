Setup Wizard & eBay Account Setup

To connect WooCommerce with eBay, you need valid credentials from the eBay Developers Program. WooCommerce eBay Connector includes an Interactive Setup Wizard that guides you through obtaining, entering, and testing these credentials in real time.

The Interactive Setup Wizard

The setup wizard automatically launches on your first visit to Webkul WC Addons → WC Ebay Connector if no accounts are configured. You can also re-run it at any time from the Help & Support drawer in the admin header or by visiting admin.php?page=fmebay-setup&from_help_tab=1.

Step 1: Welcome & Prerequisites

The welcome step reviews required permissions and credentials. Click Let's Go! to begin the guided setup, or click Skip Setup to proceed directly to manual account configuration.

Step 2: API Keys Configuration

Select your operating environment and enter your developer keys:

  1. Environment:
    • Sandbox: For testing without real orders or listing fees.
    • Production: For live eBay selling.
  2. App ID (Client ID): Generated in your eBay Developer account for your application.
  3. Dev ID: Developer identifier assigned to your developer account.
  4. Cert ID (Client Secret): Private key certificate paired with your App ID.
  5. RuName (Redirect URL Name): eBay redirect URL name used for OAuth authentication.

Step 3: eBay User Token

Generate and paste your eBay User Token:

  1. Log in to the eBay Developer Portal.
  2. Navigate to Application Keys → User Tokens.
  3. Sign in to your eBay merchant account and grant application permissions.
  4. Copy the resulting Auth Token and paste it into the eBay User Token field in the wizard.
  5. Click Verify Credentials. The connector performs a live API handshake to verify connectivity.

Step 4: Store Information & Defaults

Configure fundamental store settings for this eBay account:

  • Store Name: An internal reference label (e.g., "Webkul US Store").
  • eBay Site ID: The specific marketplace territory (e.g., US, UK, Australia, Germany, France, etc.).
  • Currency: Primary currency matching the eBay site (e.g., USD, GBP, AUD, EUR).
  • Default Category: The fallback WooCommerce category assigned to imported products when no matching category exists.

Step 5: Ready & Next Steps

Upon successful verification, the wizard confirms your store is configured and provides quick navigation links to:

  • Go to Dashboard (Account List)
  • Configure Policies (Settings)
  • Import Categories (Category Management)

Multi-Account Management

The Account List displays all connected accounts in responsive cards:

From each account card, you can:

  • Check API Limits: Query eBay API quota consumption in real time.
  • Manage Account: Open the account workspace containing all tabs for categories, products, orders, templates, and settings.
  • Edit Account: Update keys, store name, or re-verify tokens without re-entering unchanged credentials.
  • Delete Account: Remove an account and its associated mapping metadata with modal confirmation.
