Product Listing & Import Management

The Products tab (WC Ebay Connector → Manage Account → Products) serves as the management center for items imported from your eBay seller account into WooCommerce.

1. Product Table Overview

The table displays all imported products and their current synchronization status:

  • Thumbnail: Featured image synchronized from the eBay listing.
  • Product Title: Product name linked to the WooCommerce product edit screen.
  • WooCommerce Product ID: Local WordPress post ID.
  • eBay Item ID: Global 12-digit eBay marketplace item identifier.
  • Product Type: Simple or Variable product indicator.
  • Stock & Regular Price: Real-time stock count and price in store currency.
  • Sync Status: Indicator showing whether the item is active, updated, or excluded.

2. Importing Products from eBay

Merchants can import products through several flexible methods:

  1. Import All Active Listings:
    • Click the Import Products button.
    • The connector queries eBay's Trading API (GetMyeBaySelling) to retrieve all active items.
    • Products are queued in the background and processed in manageable batches.
  2. Import by eBay Product IDs:
    • Provide a comma-separated list of specific 12-digit eBay Item IDs.
    • The connector fetches only those individual items.
  3. Background Image Processing:
    • Product text and pricing are created immediately, while high-resolution images import asynchronously in the background.
    • A live progress notice displays remaining images, with pause and resume controls.

3. Updating Products from eBay

When listings are modified directly on eBay:

  • Select products using the row checkboxes and choose Update from eBay from the bulk actions dropdown.
  • Alternatively, click the Update action on an individual product row.
  • The update pulls revised variation attributes, secondary images, item condition descriptions, and updated shipping rates into WooCommerce.

4. Rate-Limit Auto-Pause & Resume

To protect your eBay seller account from API throttling:

  • The connector actively monitors daily API consumption (RemainingCallCount).
  • If call limits approach threshold boundaries, the background import queue automatically pauses.
  • An administrative banner notifies you of the reset window and provides a Resume Now override button once new calls become available.
  • You can inspect your live API usage, tracked calls, and reset timers at any time via the Real-Time eBay API Limits Monitor on your account card.
